# Gossip

Arquivo diário de descobertas públicas das áreas de entretenimento da [Unitel](https://unitel.bo/).

Este repositório guarda títulos, categorias, links e resumos curtos. O conteúdo completo permanece no site original. As atualizações são feitas pelo script `scripts/update-unitel-gossip.mjs`.

## Categorias

- [Farándula](https://unitel.bo/noticias/farandula)
- [Virales](https://unitel.bo/noticias/virales)
- [Insólito](https://unitel.bo/noticias/insolito)
- [Tendencias](https://unitel.bo/noticias/tendencias)
